# Security

[Deutsch](SECURITY-de.md)

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/deckerweb/connect-for-shopware/security/advisories/new). Include the Connect for Shopware, WordPress, PHP and relevant Bricks/Shopware versions; for bundled components include Updater 2.1.0 and Library 0.6.0. Do not post credentials or sensitive customer data in public issues.

Use the latest stable release. The Store API key stays server-side; no credential is bundled or displayed in settings. The Connector reads product data and sends visitors to the shop for checkout.
