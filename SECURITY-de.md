# Sicherheit

[English](SECURITY.md)

Vermutete Sicherheitslücken über [private GitHub-Sicherheitsmeldungen](https://github.com/deckerweb/connect-for-shopware/security/advisories/new) melden. Versionen von Connect for Shopware, WordPress, PHP und gegebenenfalls Bricks/Shopware nennen; bei eingebetteten Komponenten Updater 2.1.0 und Library 0.6.0 angeben. Keine Zugangsdaten oder sensiblen Kundendaten in öffentlichen Issues veröffentlichen.

Das neueste stabile Release verwenden. Der Store-API-Schlüssel bleibt serverseitig; kein Schlüssel wird mitgeliefert oder in den Einstellungen angezeigt. Der Connector liest Produktdaten und führt Besucher zum Checkout in den Shop.
